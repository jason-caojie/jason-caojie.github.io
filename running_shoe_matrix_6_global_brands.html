对你观察的进一步拆解

1. ASICS：最标准的“多IP专业训练矩阵”

ASICS 的命名基本是一条产品线对应一个稳定任务：

IP核心任务
METASPEED比赛日竞速
MAGIC SPEED / SONICBLAST速度训练、节奏跑
NOVABLAST / CUMULUS日常训练
NIMBUS高缓震、恢复、长距离慢跑
KAYANO / GT-2000稳定支撑
SUPERBLAST高级长距离训练 / super trainer

ASICS 最大特点是：每条产品线的训练任务边界很清楚。这也是为什么它适合研究“专业跑者训练周期矩阵”。

2. Saucony：和ASICS最像，但更强调“Endorphin速度家族 + 传统训练线”

Saucony 也很接近多IP矩阵：

IP核心任务
Endorphin Elite / Pro比赛竞速
Endorphin Speed速度训练
Ride日常跑量
Triumph高缓震
Guide / Omni / Echelon稳定支撑
Kinvara轻量自然跑 / 短距离快跑

Saucony 的结构比 Nike 更“跑店化”、比 HOKA 更“传统训练体系化”。它值得研究的不是某一双爆款，而是如何用一套长期稳定产品线覆盖完整跑步周期。Saucony官方买手指南明确把 Race、Road Neutral、Max Cushioning、Stability 分开组织。(Saucony)

3. Nike：多IP很强，但不是最“体系化”的跑步品牌

Nike 也有清晰IP，但它的特点是超级产品IP强于训练体系表达：

IP核心任务
Alphafly / Vaporfly竞速旗舰
Streakfly短距离竞速
Zoom Fly竞训
Pegasus日常万能训练
Vomero高缓震保护
Structure支撑稳定
Motiva走跑结合 / 慢跑生活方式

Nike 当前路跑货架明确出现 Alphafly 3、Vaporfly 4、Zoom Fly 6、Pegasus 42、Vomero 18 / Plus / Premium、Structure Plus 等关键产品。(Nike.in)

所以你的观察是对的，但要补一句： Nike像ASICS/Saucony，但更偏“英雄产品IP + 大众基本盘”，不如ASICS那样训练体系感强。

4. HOKA：接近多IP矩阵，但品牌母心智更强

HOKA 也有不同IP：

IP核心任务
Cielo X1 / Rocket X比赛竞速
Mach X / Mach速度训练
Clifton / Skyflow日常训练
Bondi / Skyward X高缓震保护
Arahi / Gaviota稳定支撑
Transport通勤 / 城市生活

但HOKA和ASICS/Saucony不同： 它不是靠“每个系列各自成IP”来驱动心智，而是整个品牌都被一个母心智覆盖：厚底、高缓震、滚动、轻松跑。HOKA官方对 Road Running Shoes 的说明就强调 generous cushioning、stable platform；Cielo X1 3.0 则被官方定义为 race day 的轻量超级鞋，Mach X 2被描述为 speedwork 用速度训练鞋。(HOKA)

所以 HOKA 更像： 母品牌哲学很强，子IP负责场景分工。

5. On：多IP外观最强，但专业训练体系仍在完善

On 的产品名看似也很多，但它最强的是视觉识别和城市生活方式IP，不是传统跑步训练体系。

IP核心任务
Cloudboom比赛竞速
Cloudflow / Cloudboom Max速度训练
Cloudmonster / Cloudsurfer日常跑量、高缓震
Cloudrunner稳定、初跑、保护
Cloud 6 / Cloudtilt / Cloudswift城市通勤、全天穿着

On官方路跑页能看到 Cloudboom Strike 定位 fast road running / full marathons / race day，Cloudboom Volt 定位 race day / fast ride，Cloudmonster 3定位 everyday running / responsive ride，Cloud 6 和 Cloudtilt则被标注为 travel、all-day wear、all-day comfort。(On Shop)

所以On和HOKA相近，但又不同： HOKA是高缓震哲学外溢到生活方式；On是城市设计感反向强化跑步科技。

6. adidas：最明显的“两大母线”结构

你的观察最准确的部分就是adidas。

adidas 不是把每个功能都独立成一条强IP，而是先分成两大跑步母线：

母线任务边界子款
Adizero快、轻、比赛、竞训、提速Adios Pro、Pro Evo、Boston、Evo SL、SL2、Takumi Sen
Supernova日常、有氧、入门、舒适、支撑Rise、Prima、Solution
Ultraboost跑步生活方式、高端舒适、通勤跑Ultraboost 5 / 5X

Adizero是速度母线，官方Adizero页面列出 Adios Pro 4、Evo SL 等产品，并强调EnergyRods和轻量竞速表现；Supernova页面则强调 build mileage、comfort、support；Ultraboost页面强调 Boost 能量回馈、袜套式贴合和跑步生活方式属性。(adidas KR)

所以adidas的架构可概括为：

Adizero = performance speed universe
Supernova = everyday running universe
Ultraboost = running lifestyle universe

这和ASICS/Saucony/Nike的“多个系列IP分别占位”确实不同。

类型品牌架构特点

最终判断：你的观察方向是准确的。 如果做品牌战略或商品规划，ASICS / Saucony / Nike 应该作为“多IP功能矩阵”样板，HOKA / On作为“母品牌心智驱动的产品矩阵”样板，adidas则是“速度母线 + 日常母线”的独特样板。
